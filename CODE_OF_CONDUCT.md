# Community conduct

Help people contribute regardless of experience, language or background.

- Discuss code and evidence; do not attack people.
- Explain tradeoffs respectfully and welcome corrections.
- Do not harass, threaten, discriminate against, or publish private information
  about another contributor.
- Do not post credentials or third-party media in public discussions.

Maintainers may edit or remove harmful content and restrict participation to
protect contributors. Apply these rules consistently and explain moderation
decisions when doing so does not disclose private information.

Repository maintainer: [@romanticamaj](https://github.com/romanticamaj).
For a routine moderation request, open an issue containing only public facts.
For harassment or exposed private information, use GitHub's built-in reporting
tools; do not repost the sensitive material. A separate private conduct contact
has not been published yet. Security vulnerabilities use [SECURITY.md](SECURITY.md).
