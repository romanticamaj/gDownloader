# Working name: gDownloader

The local folder and public project name are `gDownloader`, as requested. It is
short and broad enough for future non-video downloads, but it is not a distinctive
name today.

As checked on 2026-11-17, related projects already include:

- [hstr0100/GDownloader](https://github.com/hstr0100/GDownloader): a GUI for yt-dlp,
  gallery-dl and spotDL.
- [xfuentes/gDownloader](https://github.com/xfuentes/gDownloader): a GNOME front end
  for JDownloader.

Decision on 2026-11-17: publish the foundation as `romanticamaj/gDownloader`, with
clear independent-project positioning. The known discoverability collisions remain
documented; they do not block the authorized launch. This is a naming record, not
a trademark or legal clearance.

GitHub owner/repository: `romanticamaj/gDownloader`. Chrome listing, npm scope and
domain have not been reserved. Lowercase internal package names are only placeholders until scoped
workspace manifests are introduced; package availability is not assumed.
